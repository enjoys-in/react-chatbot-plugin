## Running the Demos

```bash
# Install dependencies
bun install

# Start the demo app
bun run dev
```

The demo app at `http://localhost:3000` has **24 interactive demos** covering every feature, organized by category (Basic, Forms, Advanced, Components, Plugins). Click any card to load that demo, then open the chat widget.
